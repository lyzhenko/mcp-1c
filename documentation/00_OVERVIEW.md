# Обзор

MCP-сервер отдаёт AI-ассистенту две вещи:

1. **Справку по платформе 1С:Предприятие** — глобальные методы и свойства, типы, перечисления
   и их значения, сигнатуры с параметрами и конструкторы. Источник — установленный
   синтакс-помощник (`shcntx_*.hbk`).
2. **Разбор выгрузки конфигурации** («Выгрузить конфигурацию в файлы») — объекты метаданных,
   реквизиты, табличные части, формы, команды, макеты, модули и процедуры, ссылки на объекты
   из кода и запросов, точки входа, поиск по тексту и проверка модуля.

## Инструменты

| Инструмент | Назначение |
|---|---|
| `search` | поиск по имени, английскому имени и описанию с ранжированием и подсказками |
| `info` | точная карточка элемента: сигнатуры, параметры, примеры, примечания |
| `getMember` | метод, свойство или значение перечисления конкретного типа |
| `getMembers` | состав типа страницей |
| `getConstructors` | конструкторы типа |
| `dumpOpen` | открыть выгрузку и построить/переиспользовать индекс |
| `dumpSearch` | объекты, реквизиты и процедуры выгрузки |
| `dumpMetadata` | карточка объекта: реквизиты, табличные части, формы, модули |
| `dumpCode` | текст модуля с номерами строк |
| `dumpGrep` | поиск по тексту модулей с владельцем и процедурой |
| `dumpEntrypoints` | обработчики форм, подписки, задания, HTTP/веб-сервисы |
| `dumpCheck` | проверка модуля или черновика без запуска 1С |
| `dumpNode` | карточка процедуры, модуля или объекта метаданных |
| `dumpNeighbors` | входящие/исходящие вызовы и обращения к метаданным |
| `dumpTypes` | таблица символов модуля с выводом типов |
| `dumpRights` | права ролей и условия RLS |
| `dumpSimilar` | похожие процедуры по вызовам и метаданным |
| `dumpConventions` | базовые конвенции кода 1С |
| `dumpReload` | перестроить индекс после правок |
| `status` | состояние справки и индекса, версии, кэш, установленные платформы |

Ответы — JSON. У найденного элемента есть `kind`; у страниц — `total`, `returned`, `nextOffset`,
`hasMore`; при сокращении по размеру — `truncated` и подсказка.

## Транспорты

- **stdio** (по умолчанию) — процесс запускает MCP-клиент; stdout принадлежит протоколу.
- **SSE** — HTTP-сервер для сетевого доступа: `--mode sse --port 8080`.

## Быстрый старт

```bash
./gradlew clean bootJar
jar=$(ls -t build/libs/mcp-bsl-context-*.jar | head -1)
java -Dfile.encoding=UTF-8 -jar "$jar" \
  --platform-path "/path/to/1cv8/8.3.27.2214" \
  --dump "/path/to/dump"
```

В PowerShell те же ключи, но `-D...` в кавычках и продолжение строки — обратный апостроф:

```powershell
$jar = (Get-ChildItem build/libs/mcp-bsl-context-*.jar |
        Sort-Object LastWriteTime | Select-Object -Last 1).FullName
java "-Dfile.encoding=UTF-8" -jar $jar `
  --platform-path "C:\Program Files\1cv8\8.3.27.2214" `
  --dump "D:\dump\1c_files"
```

Без `--platform-path` сервер ищет установленную платформу в стандартных каталогах ОС и берёт самую
свежую версию. Язык справки — `--locale ru|en`. Без `--dump` выгрузку можно открыть инструментом
`dumpOpen`.

## Что происходит при старте

1. Сервер находит `.hbk` и проверяет дисковый кэш разбора.
2. При промахе разбирает справку в фоне (на 8.3.27 — около 2 секунд; из кэша — доли секунды).
3. Если задан `--dump`, строит или открывает SQLite-индекс выгрузки (6,1 ГБ — около 15 секунд).
4. `status` отвечает сразу; инструменты ждут готовности не дольше своих таймаутов и иначе
   возвращают `platform_not_ready`/`dump_not_ready` с просьбой повторить.
